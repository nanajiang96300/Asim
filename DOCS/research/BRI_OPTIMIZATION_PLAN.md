# BRI优化路线与重建状态

日期：2026-11-09（Asia/Hong_Kong）。初版讨论记录以2c4c91da为核对基点；现已完成隐式候选实际接入与新留出，见[接入报告](../../experiments/bri_implicit/2026-11-09-v1/README.md)。旧论文快照不覆盖，原始结果按各自契约/版本解释。

## 研究方向与适用条件

令A=HᴴH+λI，D=blockdiag(Ajj)，P=D⁻¹。正确迭代X←X+ωP(I−AX)，固定步长要求ρ(I−ωPA)<1；λ>0且P正定时等价0<ω<2/λmax(PA)。若使用Y与T=PA，必须最终X=YP，不能混用P/T。CDL-B本身不是可用/不可用判据；相关性、正则化、预条件谱和有限精度共同决定适用域。高SNR通常对应更小λ，弱空间方向更难求解，但不代表所有CDL-B矩阵都病态。

依次区分：公式/恢复错误、谱越界发散、收敛慢、显式Gram量化平台、残差/更新舍入。只增加K不能解决前述全部问题；不能改λ或放宽门限让测试通过。Chebyshev需要包谱区间，稳定递推、前态和谱界来源均有成本。块增大、流重排或更好预条件器属于候选变体，不保证总周期改善。

优先现有FP16路线：隐式残差Hᴴ(y−Hx)−λx、单侧复表示、阻尼/补偿更新；冻结校准与新留出后再映射原生程序。当前可行基线为点Jacobi，不是历史最快的大块BRI。输入FP16与FP32临时累加假设必须显式声明，不改称纯FP16算术。大块预条件、流重排和谱界改进后续在同任务下比较。

## 可选混合精度设计：待验证，非当前前置

目标是低精度求修正、高精度算残差并维护解，不是所有操作统一升FP32：

1. H、低精度块预条件和内层工作张量优先FP16；内层BRI的累加/舍入点显式冻结。
2. 外层用FP32计算并保存r=Hᴴ(y−Hx)−λx，以少量低精度BRI近似求Ad=r，再用FP32状态执行x←x+d。显式逆任务相应使用R=I−AX，近似求AΔX=R，更新X←X+ΔX。
3. FP32保存外层解、残差、系数；最终按契约转FP16后重新验收。也可对比FP32显式Gram，但必须计入构建、存储、转换及DMA。
4. 已量化为FP16的Gram再转FP32不能恢复丢失信息；高精度残差需针对声明的原始/输入量化系统计算。只有FP16输入H时仍须统计输入量化误差。
5. 内层修正必须有效降低外层误差；高精度残差不保证任意条件数下收敛。冻结内/外迭代预算、缩放及恢复，失败保留；参考依据为[Carson–Higham三精度迭代改进](https://eprints.maths.manchester.ac.uk/2629/)。这只是设计依据，不是本项目混合精度已达标的证据。

持久FP32张量将涉及Asim精度协议、地址/布局、转换指令与吞吐/周期建模。当前未实现/验收；本次记录方向不授权直接扩展仿真器。先完成现有FP16候选闭环，再单独评估扩展的质量—周期收益。

## 重建能力与缺口

已实现并有阶段验收：实际Instruction/view/常量与初始化/读写语义重放；共同H/Y/λ任务与完整计时边界；Asim先行及性能预筛；同算法精度参考和FP64任务参考分开；未知语义失败关闭；源码/输入/契约/runtime绑定；真实事件保守读写检查；七个新入口在声明瑞利域的三路径与未编码QPSK验证。不是根据算法名调用标准算法代替实际指令。

尚不能称全部完善：

- 旧七入口未全修复，七新入口也未全部通过CDL-B。直接法/NS在病态域还有实块象限一致性拒绝，不能关闭该门禁或只取左块宣称通过。
- 隐式FP16研究程序的CONST/COPY、补偿/前态、标量系数和单侧复布局现已完成原生指令映射及实际输出位一致验证；它仍不能替代新CDL质量门禁。
- 当前精度模型是FP16存储/固定顺序FP32临时算术；不是硬件精度认证。硬件时序由负责人上板，不列为本轮阻塞。
- 新候选实际周期/流水及跨算子统一CDL正确性比较、正式评分晋级和无人值守控制器未完成；score保持null。观察日志流式内存优化与新增形状/信道域覆盖可后续推进。
