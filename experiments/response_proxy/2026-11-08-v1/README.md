- 七个显式新入口：复用同一seed42/batch0的H，每算法一个配置，175次实际指令重放。

本轮**未运行新的C++ Asim、未修改算子/解释器/参考/runtime**。源程序已通过原Asim/事件/数值门禁，
本轮固定原序列、地址/形状/精度，只做显式Y输入的离线诊断；不改变原周期、不计算加速比。

## 负例与门禁含义

严格要求max_prediction_error=0，100次真实重放仍和独立FP16参考位一致，
但全部4个配置RESPONSE_MODEL_REJECTED，整体PROBE_GATE_FAILED，且**不输出SE代理**。
这是预期拒绝：有限精度不等于严格线性，不是算子/重建实现出错。

将预算设为1次，预检PROBE_REJECTED，原因为probe replay budget exceeded；无NPZ探针制品。
结果actual_replay_calls为null表示未形成完成计数；“未进入重放”另由预算前置代码路径及单元测试确认。

12项新增测试还覆盖复线性/共轭响应、非线性、偏置、RHS混合、零行/滤波后噪声、
逐流缩放不改变SINR、代理损失、非有限输出、解释器/oracle失败，以及正常Y必须重现归档输出。
